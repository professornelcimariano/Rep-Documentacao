# app-blog 
 
Sistema de blog com área pública e painel administrativo. 
 
## Tecnologias 
- PHP 8 
- MySQL 
- HTML e CSS 
 
## Funcionalidades 
- Front-end: listar e ler postagens 
- Painel admin: login, criar, editar e excluir postagens 
 
## Como executar 
1. Instale o XAMPP e inicie o Apache e o MySQL 
2. Copie a pasta app-blog para htdocs 
3. Importe o arquivo banco/app_blog.sql no phpMyAdmin 
4. Acesse http://localhost/app-blog

## Estrutura de pastas 
- /admin: painel administrativo 
- /public: páginas do front-end 
- /css: estilos 
- /includes: conexão com o banco e funções 
- /banco: script SQL 
- /docs: documentação
